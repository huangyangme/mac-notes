使用 Windows To Go 制作外置启动盘并不复杂。但是在 Mac 上制作给 Mac 用的 Windows To Go 外置启动盘就稍微复杂一些。

## 所需材料

- 一个可以运行的 Windows 系统
- Windows 系统镜像[[download-windows-ios]]
- 一个性能优异的 USB存储设备（固态硬盘/高性能机械硬盘/固态U盘）
- 一个有线鼠标
- 一个普通 USB 存储设备


## 开始

### 1、下载 Windows 支持软件

打开 macOS「启动转换助理」，点菜单栏「操作-下载Windows支持软件」，选择一个保存的位置。然后点「存储」。接着就是等待下载完成。下载大概花了 10 分钟。

![[2020-07-12 10.10.45.ca19a474959d411fba16cc2df4f4d2ff.jpg]]

下载好的应该是一个名叫 `WindowsSupport` 的文件夹，把文件夹拷贝到提前准备的普通 USB 存储设备里。可以是普通的 U 盘或移动硬盘甚至 SD 卡都行，容量大于4G就行了。格式必须是 Windows 支持的，比如 ExFAT 或 NTFS。

假设你是用 U 盘保存这个 `WindowsSupport` 文件的，下文叫它「普通U盘」。

### 2、准备移动硬盘或U盘

安装 Windows 的外置存储可以是**高性能机械硬盘**或者**固态硬盘（SSD）**，如果选择 U 盘的话，普通 U 盘是不行的，要选择**固态闪存U盘**。不是安装非常大的软件或游戏的话，128G 就够了。

### 3、Mac 的准备

如果你的 ** Mac 配了 Apple T2 安全芯片，还需要先开启「允许从外部介质启动」**才能使用 Windows To Go。如果不是 T2 安全芯片的 Mac 则直接忽略这一步准备。

在苹果 () 菜单打开「系统信息」，在边栏选择「控制器」，在右边能看到「Apple T2 芯片」的就是。

把 Mac 关机，然后按电源键开机。看到屏幕出现白色  图标，马上按 ⌘-R ，并显示进度条后松开。稍等一下，会进入「macOS 实用工具」。在顶部栏选择「实用工具-启动安全性实用工具」。

![[DSC04966.3bf1cd8d82e945dda741f1e347e08364.jpg]]

然后把「允许的启动介质」勾选到「允许从外部…」。关掉窗口，然后重启 Mac。

![[DSC04968.afd4f605d8c64574b1579befc0bf3752.jpg]]
—

准备工作完成，下面开始制作。

制作 Windows 外置启动盘有两种方法，一种是官方提供的「Windows To Go」，比较简单但是限制比较多；一种是使用第三方开发的工具来安装。

可以先打开你身边的 Windows 电脑，或者 Mac 装了 Boot Camp 双系统的 Windows。搜索一下 Windows To Go，如果有，就用这个官方的 Windows To Go 工具，如果没有，就下载使用第三方「WTG辅助工具」。

### 官方工具安装

首先需要一台装了 Windows 10 企业版或教育版的 PC。因为只有这种版本上才有 Windows To Go 工具。

如果你跟我一样没有 PC 电脑，也可以在 Mac 上通过虚拟机或者「启动转换助理」来安装 Windows 10 企业版或教育版镜像。我比较推荐使用「启动转换助理（Boot Camp）」，会更稳定。

Windows 10 企业版镜像可以在 `msdn.itellyou.cn` 这个网站下载。找到名字带 `business editions` 就是企业版。如果不知道下哪个链接，可以在公众号后台回复「**WTG**」获取 P2P 下载链接，在 Mac 用迅雷下载非常快（不需要会员）。

把下载的 Windows 10 企业版镜像拷贝到固态U盘中。然后进入 Mac 的 Boot Camp 或虚拟机里的 Windows 系统。再把固态 U 盘里面的企业版镜像拷贝到 Windows 系统中。然后双击 windows 系统里的镜像来装载。

![[2020-07-12 9.57.33.38c30d4546684f509b4fee514899a812.jpg]]
搜索「Windows to go」并打开。

![[2020-07-12 9.58.11.c347f213f8f84ed194e09b7e2b819981.jpg]]

程序会识别出 USB 驱动器，也就是你的固态 U 盘。忽略提示，点下一步。

![[2020-07-12 9.58.27.cc50ac4e40944a36b71a1026583a4d6f.jpg]]

程序自动找到装载的 Windows 10 企业版镜像，点下一步。

![[2020-07-12 10.00.04.d341ab8d5b2f43ffb783da989456f32e.jpg]]

「设置 BitLocker 密码」可以留空，直接跳过。

点「创建」，创建 Windows To Go 工作区，等待大概十分钟。

![[2020-07-12 10.01.03.9e33a000a0c044f9b7a8c59201c0c154.jpg]]
选择一个启动选项，我选的「否」，保存并关闭。

至此，使用官方的 Windows To Go 制作 Windows 外置启动盘就做好了。

### 第三方工具安装

使用第三方工具安装对 Windows 系统版本没有那么多限制。随便打开一台安装了 Windows 8/8.1/10 的 PC 或 Mac。然后下载安装一个叫「WTG 辅助工具 」的软件。

「WTG 辅助工具」下载地址👉 `https://dl.luobotou.org/wtga5420.zip`
![[{816E979D-F6DF-4292-8BA4-1BCEA433E6F1}.9eba880830074a50879a26a9af523419.jpg]]

打开「WTG 辅助工具 」，点击「浏览…」选择 Windows 镜像，下面一行选择你插上去的固态U盘。其他的默认就行了。然后就是等待制作完成。
![[{40C84437-AD6F-41D8-B635-DA6095296449}.ba1119c69d0c4e4a8490f1533df798df.jpg]]
![[{65BEF73C-209B-420E-8A53-8CFD1167E186}.8b049b73dafc4d03bc08099cd5ff9338.jpg]]

通过上面任意一种方法，就制作好了一个 Windows 外置启动盘。但是要想让它在 Mac 上使用，还需要一些工作。

### 6、启动并设置 Windows

现在我们来试试制作好的 Windows 启动盘。

把 Mac 关机，插上固态U盘。开机按住 `option` ，启动选项选择橙色的「EFI Boot」，这就是 Windows 启动盘。

![[DSC05010.6f10174ecbbf4ad4aab8a3e134e6c558.jpg]]
选择并进入固态 U 盘的 Windows。

到第一个设置界面，需要选择地区，这时候你会发现 Mac 触控板和键盘都无法使用。这是因为现在这个 Windows 没有支持软件，很多针对 Mac 的驱动都没有安装，算是一个「半成品」Windows To Go。所以需要一个有线鼠标。

把有线鼠标连上 Mac。在区域设置界面选择并往下走。

接下来会遇到另一个坑，需要输入用户名。如果有 USB 键盘，插上去输入就可以了。如果跟我一样没有，可以鼠标点左下角辅助工具，选择「屏幕键盘」，然后用光标点着输入。后面就跟着引导设置就行了。


顺利的话，现在已经进入外置存储里的 Windows 了。先别忙着高兴，下面还有很关键的一步。


## 安装 Windows 支持软件

现在的 windows 缺少很多必要的驱动，所以像键盘、触控版、蓝牙、网络、声音等等都是不能用的。这时候要先安装一个东西。

还记得第一步下载的 Windows 支持软件吗？你已经把它拷贝到普通 U 盘里了。现在把它插在 Mac 上，把里面的`WindowsSupport` 文件夹复制到 Windows 的一个地方（我是放在「下载」文件夹里）。


复制好后打开``WindowsSupport` 文件夹里的 `BootCamp`` 文件夹，里面有个叫 `Setup` 的可执行程序，双击打开，就像正常安装 Windows 软件一样。一路下一步，然后等待安装完就行了。安装过程中会不时的黑屏几次，这是正常的。
![[DSC05022.93d1030f309a49e7bc2d153e895ecaac.jpg]]
等安装结束，重启 Windows 再进入，就是一个完成的 Windows 系统了。可以正常链接网络、使用 Mac 键盘和触控板。（如果像上图那样卡在进度条100%的位置几分钟不动，实际上也已经安装好了，不要管它，直接重启 Windows）

好了，你已经成功的制作可以用在 Mac 上的 Windows 启动盘了！

## 总结和补充

- T2 安全芯片的 Mac 一定要先开启「允许从外部介质启动」，否则可能会误以为是启动盘制作出了问题（我就在这一步卡了好久）
- 如果你的 Mac 本地闪存存储空间足够，并且只在这一台 Mac 上用 Windows。用「启动转换助理」的方式安装 Windows 双系统会比 Windows To Go 更简单，也更省钱省事。
- Windows To Go 的好处是可以用在任意一台 Mac 或 Windows 电脑
- 微软对 Windows To Go 已经停止开发并不再更新支持。
- 未来自研 ARM 架构的 Mac 可能会彻底和 Windows 拜拜，黑苹果可能也会慢慢退出历史舞台。
- 运行 Windows 的 U盘或移动硬盘发热是很正常的。电脑里的硬盘也会发热。U盘比移动硬盘可能发热会更明显一些。
- 在 Windows 上使用 Windows To Go 启动盘会方便很多，因为很多驱动都自带了。
