APFS 是 Apple 设备的新文件系统格式，APFS 格式磁盘（比如移动固态硬盘）连在 Windows 上无法直接读写。

安装以下 Windows 软件可以实现 APFS 磁盘在 Windows 上读写。

- [MacDrive](https://macdrive.com)（付费）
- [APFS for Windows by Paragon Software](https://www.paragon-software.com/home/apfs-windows/)（付费）
