在Mac 中，我们自己创建的文件夹显示图标都长一个样。如何改变文件夹的默认显示样子呢？这里教大家一个不需要使用第三方软件的方法。

第一步准备一张图片，双击打开，然后按快捷键 `command` + `C` 来拷贝。

第二步，在我们想修改的文件夹上右键选择「显示简介」（也可以用快捷键 command + I）。然后在出来的简介窗口点上面这个小图标，注意不是下面的大图标。点中后按 command + V 粘贴。文件夹显示图标就会变成第一步打开的图片的样子。

如果改完后后悔了，可以马上按一次 command + Z 键来撤销操作。

如果之后想改回来，可以再次打开这个文件夹的「显示简介」窗口，点上面的小图标，然后在菜单栏选择「编辑-剪切」就会恢复成默认文件夹的样子了。
