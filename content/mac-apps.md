[Squash](https://apps.apple.com/cn/app/squash-3/id1545179668?mt=12) 支持 PNG 和 JPEG 压缩。

## Windows 读写 APFS

APFS 是 Apple 设备的新文件系统格式，APFS 格式磁盘（比如移动固态硬盘）连在 Windows 上无法直接读写。可通过安装以下软件实现 APFS 磁盘在 Windows 上读写。

- [MacDrive](https://macdrive.com)（付费）
- [APFS for Windows by Paragon Software](https://www.paragon-software.com/home/apfs-windows/)（付费）
