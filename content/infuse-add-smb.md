在 Mac 「文件共享」设置的「SMB文件共享」下面勾选一个账户并设置密码，然后在 Infuse 上用这个账户和密码关联共享文件夹。

![[2025-07-14 16.31.54.jpg]]

同样适用于 VidHub、网易爆米花等通过 SMB 关联访问 Mac 文件的情况。

如果想要 Windows 访问 Mac 共享文件，也要勾选一个 Windows 文件共享账户，然后在 Windows 上登录。
