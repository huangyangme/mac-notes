  

iQunix 部分新款键盘（比如 MG65）已经支持 VIA 改键，使用 Chrome 打开 [usevia.app](https://usevia.app/) 即可。

下面以 Magi 65/Magi 65 Pro 为例介绍通过 VIA 键的方法。

  

步骤 1：通过有线连接键盘。

  

步骤 2：下载 [JSON 文件](https://drive.google.com/file/d/1GIqheLA4HsmfC9HsddTAXccMDcA-k7e6/view?usp=sharing)。

  

步骤 3：打开 [VIA](https://usevia.app/) 网站（推荐使用 Chrome） ，在设置界面找到“Show Design tab”并打开开关。

  

步骤 4：点开 DESION，并上传 JSON 文件。

  

步骤 5：连接键盘。

  

更多 iQunix 键盘不支持 VIA 浏览器改键，可以去 [iQunix 官网](https://support.iqunix.com/%E9%A9%B1%E5%8A%A8/)下载对应键盘型号的驱动软件。驱动软件目前只有 Windows 版，Mac 用户可以安装 Windows 或虚拟机来操作。安装好驱动软件，在有线模式下跟电脑连接即可修改。
