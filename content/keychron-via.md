# Keychron 客制化键盘 VIA 改键

Keychron 家的键盘支持 [VIA](http://usevia.app) 网页改键。

以 Keychron M3 Pro 为例，先把键盘通过数据线连上Mac，然后把键盘切换到有线连接模式。

接着用浏览器（建议使用 Chrome 打开，Safari 暂不支持）打开 [VIA 键位修改网站](https://usevia.app/)，然后点「Authorize device+」按钮。

此时浏览器会弹出设备连接窗口，选中你的键盘名字（比如我这里是「Keychron K3 Pro」），然后点「连接」按钮。

然后就进入改键界面啦。
 ![[640-7.2af5d7ed305b4205a47390ee7f71589c.jpg]]

其实 Keychron 也开发了自己的[网页改键](https://launcher.keychron.com/#/keymap)，功能跟 VIA 大同小异。
