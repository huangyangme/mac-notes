## 下载安装 Whisky

CPU: Apple Silicon (M-series chips)  
OS: macOS Sonoma 14.0 or later  

`brew install --cask whisky`

[https://getwhisky.app/zh-Hans/](https://getwhisky.app/zh-Hans/)

安装中文字体 cjkfonts 和 corefonts（macOS中文语言需要）

增强同步选择MSync，打开Metal HUD，关闭DVDX

[![](https://i0.hdslb.com/bfs/new_dyn/watermark/7b8a3d3a65fd09efd1580877eecbf08a66824252.png@.png)](https://i0.hdslb.com/bfs/new_dyn/watermark/7b8a3d3a65fd09efd1580877eecbf08a66824252.png@.png)

## 2、下载更新 Game Porting Toolkit 2.0

[https://developer.apple.com/cn/games/game-porting-toolkit/](https://developer.apple.com/cn/games/game-porting-toolkit/)

手动更新Game Porting Toolkit来使用苹果最新的技术

安装后需重启 Whisky

## 下载安装 Steam Win 版

可能需要科学上网  
  
[https://store.steampowered.com/about/](https://store.steampowered.com/about/)

把系统语言设为English（设置-通用-语言与地区）

Whisky 点运行，安装SteamSetup.exe  
安装Steam语言设置为英文  

安装完成后登录Steam（若遇到问题就whisky菜单-文件-停止所有容器）

正常打开Steam，把macOS系统和软件语言设置为中文。
